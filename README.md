# CommunityCAD

Community CAD nasce dall'idea di semplificare e aumentare le conoscenze di base di chi spesso usa programmi CAD 2D/3D per poterli usare con maggiore efficienza e facilità.
Qui dentro potrete trovare tutte le informazioni che vi possono servire, sia a livello teorico che pratico per poter crescere a livello professionale con l'utilizzo di programmi CAD 2D/3D.
Questo progetto nasce con lo scopo di rendere accessibile a tutti la possibilità di poter sapere e conoscere tutte le funzionalità di questi software.
